# One company per line.  That is the only required input.
#
#   python3 scan.py --csv companies_template.txt -o results
#
# Without a website the scanner derives one from the company name and then
# tries the conventional careers paths (/careers, /jobs, ...).  Supplying the
# website or careers page is optional and only improves recall:
#
# company,website,careers_url
# Specsavers,https://www.specsavers.com,https://join.specsavers.com/ca/jobs
#
# Use the CSV form when you have it:
#   python3 scan.py --csv companies.csv -o results
